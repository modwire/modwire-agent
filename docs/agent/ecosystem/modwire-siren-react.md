# @modwire/siren-react

Return to the [ecosystem map](README.md).

## Owns

Accessible React frames, command surfaces, and semantic widgets for the
framework-neutral Siren UI engine.

## Reuse in the agent

It can provide workbench structure and standard interaction surfaces for the
browser after the Siren client and UI engine are adopted. It should not replace
specialized contract-review or architecture-analysis components.

# @modwire/siren-ui

Return to the [ecosystem map](README.md).

## Owns

A framework-neutral semantic UI engine that projects Siren documents into an
immutable UI graph, applies safe presentation rules, and drives advertised
relation and action transitions through a session.

## Reuse in the agent

Use it for generic navigation, action forms, loading state, diagnostics, and
ordinary resource presentation. Keep purpose-built plan review, diagram, and
architecture-finding visualizations outside this generic engine.
